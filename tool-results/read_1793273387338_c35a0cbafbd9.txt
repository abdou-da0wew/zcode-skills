     1→     1→# Mermaid Template Library
     2→     2→
     3→     3→> **⚠️ Before writing any code, read [`_rules.md`](references/_rules.md) — three non-negotiable rules on overlap, hierarchy, and color.**
     4→     4→
     5→     5→
     6→     6→Mermaid is the best "text-as-diagram" solution — write structural diagrams with Markdown-like syntax, zero design skills needed.
     7→     7→Best for: flowcharts, sequence diagrams, architecture diagrams, Gantt charts, class diagrams, ER diagrams, mind maps, state diagrams, pie charts, Git branch graphs.
     8→     8→
     9→     9→**Core advantages**: text is version-controllable, minimal maintenance cost, high rendering consistency, CJK support.
    10→    10→
    11→    11→## ⚠️ Flowchart Quality Rules (Highest Priority)
    12→    12→
    13→    13→### Font Size Control
    14→    14→Mermaid font sizes are controlled via `themeVariables` and CSS:
    15→    15→- `fontSize`: Global font size, recommended `14px`-`16px`, **no less than 12px**
    16→    16→- Node text is controlled via `fontSize` or `%%{init:}%%` directive
    17→    17→- Annotations/footnotes use subgraph titles or separate nodes, font size no less than `11px`
    18→    18→
    19→    19→### Connectors & Spacing
    20→    20→```javascript
    21→    21→flowchart: {
    22→    22→  padding: 32,           // Node padding (CJK needs more space)
    23→    23→  nodeSpacing: 80,       // Horizontal spacing between nodes (default 50 too tight, 60 still not enough)
    24→    24→  rankSpacing: 80,       // Vertical spacing between ranks
    25→    25→  curve: 'basis',        // Connection curve style, consistent across the chart
    26→    26→}
    27→    27→```
    28→    28→
    29→    29→**Connector style must be consistent throughout the chart**: do not mix straight, curved, and polylines in the same diagram. Mermaid controls this globally via the `curve` parameter.
    30→    30→
    31→    31→### ⚠️ Mermaid Flowchart Hard Constraints (MANDATORY)
    32→    32→
    33→    33→The following constraints are enforced **when generating Mermaid flowchart code**, not as post-checks:
    34→    34→
    35→    35→1. **Node text must be wrapped in quotes**: `A["用户登录"]` ✅ / `A[用户登录]` ❌ — quotes prevent CJK special characters from causing parse errors
    36→    36→2. **Max 10 CJK characters per line in node text**: exceed → use `<br>` to break → `A["用户身份<br>验证模块"]`
    37→    37→3. **Max 5 nodes per subgraph**: exceed → split into multiple subgraphs or switch to CSS approach
    38→    38→4. **Max 10 total nodes**: exceed → switch to CSS flowchart template in `references/playwright-css.md`
    39→    39→5. **Max 6 CJK characters in connector labels**: `-->|验证通过|` ✅ / `-->|用户身份验证通过后跳转|` ❌
    40→    40→6. **Config params must use enlarged values**: `padding: 32, nodeSpacing: 80, rankSpacing: 80`
    41→    41→

    92→    92→
    93→    93→**Python screenshot script**:
    94→    94→
    95→    95→```python
    96→    96→import asyncio
    97→    97→from playwright.async_api import async_playwright
    98→    98→
    99→    99→async def mermaid_to_png(html_path, png_path, width=1400, scale=2):
   100→   100→    async with async_playwright() as p:
   101→   101→        browser = await p.chromium.launch(headless=True)
   102→   102→        page = await browser.new_page(
   103→   103→            viewport={'width': width, 'height': 800},
   104→   104→            device_scale_factor=scale
   105→   105→        )
   106→   106→        await page.goto(f'file://{html_path}', wait_until='load', timeout=30000)
   107→   107→        
   108→   108→        # Wait for Mermaid SVG to render
   109→   109→        await page.wait_for_selector('#diagram svg', timeout=15000)
   110→   110→        await page.wait_for_timeout(1000)
   111→   111→        
   112→   112→        # ⚠️ Read SVG's ACTUAL rendered size (not CSS box model!)
   113→   113→        # Mermaid SVGs often overflow their CSS container — getBBox/clientRect
   114→   114→        # returns the true size, while CSS bounding_box() returns the clipped box.
   115→   115→        svg_size = await page.evaluate('''() => {
   116→   116→            const svg = document.querySelector('#diagram svg');
   117→   117→            if (!svg) return null;
   118→   118→            const r = svg.getBoundingClientRect();
   119→   119→            return { width: r.width, height: r.height };
   120→   120→        }''')
   121→   121→        
   122→   122→        el = page.locator('#diagram')
   123→   123→        css_bbox = await el.bounding_box()
   124→   124→        
   125→   125→        svg_w = svg_size['width'] if svg_size else width
   126→   126→        svg_h = svg_size['height'] if svg_size else 800
   127→   127→        css_w = css_bbox['width'] if css_bbox else width
   128→   128→        css_h = css_bbox['height'] if css_bbox else 800
   129→   129→        
   130→   130→        # Use the LARGER of CSS box and SVG actual size
   131→   131→        fit_w = max(width, int(max(svg_w, css_w) + 200))
   132→   132→        fit_h = int(max(svg_h, css_h) + 200)
   133→   133→        
   134→   134→        await page.set_viewport_size({'width': fit_w, 'height': fit_h})
   135→   135→        await page.wait_for_timeout(500)
   136→   136→        
   137→   137→        await el.screenshot(path=png_path)
   138→   138→        await browser.close()
   139→   139→        
   140→   140→        import os
   141→   141→        print(f'✅ {png_path} ({os.path.getsize(png_path)/1024:.0f}KB)')
   142→   142→
   143→   143→# asyncio.run(mermaid_to_png('./output/diagram.html', './output/diagram.png'))
   144→   144→```
   145→   145→
   146→   146→> **⚠️ CRITICAL: CSS `bounding_box()` vs SVG actual size**
   147→   147→>
   148→   148→> Mermaid generates SVGs that can be wider/taller than their CSS container. `bounding_box()` (Playwright) and `getBoundingClientRect()` on the container return **CSS box model size**, which may be smaller than the SVG's viewBox.
   149→   149→>
   150→   150→> **Always read the SVG element's own `getBoundingClientRect()`** via `page.evaluate()` and use `max(css_size, svg_size)` for viewport dimensions. This is the root cause of the "right side clipped" bug.
   151→   151→>
   152→   152→> Also: `wait_until='load'` is preferred over `'networkidle'` because Mermaid initializes on DOM load. `'networkidle'` can timeout if CDN is slow.

   243→   243→## Template 1: Flowchart
   244→   244→
   245→   245→The most common chart type. Supports directions: `TB` (top→bottom), `LR` (left→right), `BT`, `RL`.
   246→   246→
   247→   247→```mermaid
   248→   248→flowchart TB
   249→   249→    A[开始] --> B{条件判断}
   250→   250→    B -->|是| C[执行操作A]
   251→   251→    B -->|否| D[执行操作B]
   252→   252→    C --> E[结束]
   253→   253→    D --> E
   254→   254→
   255→   255→    style A fill:#EFF6FF,stroke:#3B82F6,stroke-width:2px,color:#1E293B
   256→   256→    style B fill:#FFF7ED,stroke:#F59E0B,stroke-width:2px,color:#1E293B
   257→   257→    style C fill:#F0FDF4,stroke:#10B981,stroke-width:2px,color:#1E293B
   258→   258→    style D fill:#F0FDF4,stroke:#10B981,stroke-width:2px,color:#1E293B
   259→   259→    style E fill:#EFF6FF,stroke:#3B82F6,stroke-width:2px,color:#1E293B
   260→   260→```
   261→   261→
   262→   262→### Node Shape Quick Reference
   263→   263→
   264→   264→| Syntax | Shape | Use For |
   265→   265→|------|------|--------|
   266→   266→| `A[text]` | Rectangle | Steps/Actions |
   267→   267→| `A(text)` | Rounded rect | General nodes |
   268→   268→| `A([text])` | Stadium | Start/End |
   269→   269→| `A{text}` | Diamond | Decision |
   270→   270→| `A{{text}}` | Hexagon | Preparation |
   271→   271→| `A[/text/]` | Parallelogram | Input/Output |
   272→   272→| `A((text))` | Circle | Connector |
   273→   273→| `A>text]` | Flag | Event/Signal |
   274→   274→
   275→   275→### Subgraphs (Grouping)
   276→   276→
   277→   277→```mermaid
   278→   278→flowchart LR
   279→   279→    subgraph 前端["🖥️ 前端"]
   280→   280→        A[React App] --> B[API 调用]
   281→   281→    end
   282→   282→    subgraph 后端["⚙️ 后端"]
   283→   283→        C[FastAPI] --> D[(PostgreSQL)]
   284→   284→    end
   285→   285→    B --> C
   286→   286→
   287→   287→    style 前端 fill:#EFF6FF,stroke:#3B82F6,stroke-width:1px
   288→   288→    style 后端 fill:#F0FDF4,stroke:#10B981,stroke-width:1px
   289→   289→```

   294→   294→
   295→   295→Shows interaction sequence between systems/actors.
   296→   296→
   297→   297→```mermaid
   298→   298→sequenceDiagram
   299→   299→    actor 用户
   300→   300→    participant 前端 as 🖥️ 前端
   301→   301→    participant API as ⚙️ API 网关
   302→   302→    participant DB as 🗄️ 数据库
   303→   303→
   304→   304→    用户->>前端: 点击登录
   305→   305→    前端->>API: POST /auth/login
   306→   306→    API->>DB: 查询用户
   307→   307→    DB-->>API: 用户信息
   308→   308→    
   309→   309→    alt 验证成功
   310→   310→        API-->>前端: 200 + JWT Token
   311→   311→        前端-->>用户: 跳转首页
   312→   312→    else 验证失败
   313→   313→        API-->>前端: 401 未授权
   314→   314→        前端-->>用户: 显示错误提示
   315→   315→    end
   316→   316→    
   317→   317→    Note over 前端,API: Token 有效期 24 小时
   318→   318→```

   320→   320→### Arrow Types
   321→   321→
   322→   322→| Syntax | Meaning |
   323→   323→|------|------|
   324→   324→| `->>` | Solid arrow (synchronous call) |
   325→   325→| `-->>` | Dashed arrow (return/response) |
   326→   326→| `-x` | Solid with x (failure/rejection) |
   327→   327→| `-)` | Async message |

   593→   593→### Auto-Upgrade Rules (Important!)
   594→   594→
   595→   595→> ⚠️ **Never trim user content just to fit Mermaid!**
   596→   596→> Content comes first; tools serve content, not the other way around.
   597→   597→
   598→   598→When content complexity exceeds Mermaid mindmap's comfort zone, **auto-switch to CSS approach** (`references/mindmap-css.md`):
   599→   599→
   600→   600→| Trigger Condition (any one met) | Action |
   601→   601→|----------------------|------|
   602→   602→| More than 7 L1 branches | → Switch to CSS |
   603→   603→| Any branch has >8 child nodes | → Switch to CSS |
   604→   604→| Nesting exceeds 3 levels | → Switch to CSS |
   605→   605→| Single node text >15 chars | → Switch to CSS |
   606→   606→| Total nodes >40 | → Switch to CSS |
   607→   607→
   608→   608→**When none of the above triggers**, Mermaid mindmap is adequate. The following suggestions help optimize rendering (recommendations, not hard limits):
   609→   609→
   610→   610→| Suggestion | Notes |
   611→   611→|------|------|
   612→   612→| Keep node text concise | Use spaces to segment long text, avoid punctuation |
   613→   613→| Use emoji prefixes per branch | Higher visual distinctiveness |
   614→   614→| Use CSS injection for coloring | Use the optimized HTML shell above |

   639→   639→### Known Limitations of Mermaid Mindmap
   640→   640→
   641→   641→- ❌ No `style` / `classDef` support for direct node coloring (CSS injection of SVG styles only)
   642→   642→- ❌ Line thickness/curvature cannot be controlled from Mermaid syntax (CSS override `.mindmap-edge`)
   643→   643→- ❌ Node spacing calculated by algorithm, cannot be manually specified
   644→   644→- ❌ Long CJK text easily overlaps with connectors (strict character count control needed)
   645→   645→- ⚠️ CSS injection depends on Mermaid internal class naming, may break on version upgrades
   646→   646→
   647→   647→**Conclusion**: For quick drafts use Mermaid + the CSS-optimized shell above; for production output use CSS mind map → `references/mindmap-css.md`

   738→   738→## FAQ
   739→   739→
   740→   740→### Q: CJK node names cause layout issues?
   741→   741→
   742→   742→Ensure `fontFamily` includes a CJK font:
   743→   743→```javascript
   744→   744→themeVariables: {
   745→   745→  fontFamily: '-apple-system, PingFang SC, SimHei, sans-serif'
   746→   746→}
   747→   747→```
   748→   748→
   749→   749→### Q: How to control node spacing?
   750→   750→
   751→   751→Mermaid auto-layouts; spacing is adjusted via config:
   752→   752→```javascript
   753→   753→flowchart: { padding: 16, nodeSpacing: 50, rankSpacing: 60 }
   754→   754→```
   755→   755→
   756→   756→### Q: Chart too large?
   757→   757→
   758→   758→- Split into subgraphs
   759→   759→- Change direction (`TB` too tall → switch to `LR`)
   760→   760→- Use `mmdc -w 1600` to increase canvas width
   761→   761→
   762→   762→### Q: How to add line breaks in nodes?
   763→   763→
   764→   764→Use `<br>` tags:
   765→   765→```mermaid
   766→   766→A[第一行<br>第二行<br><small>小字注释</small>]
   767→   767→```
   768→   768→
   769→   769→### Q: Flowchart node text truncated or overlapping?
   770→   770→
   771→   771→**Common causes and fixes**:
   772→   772→
   773→   773→1. **Insufficient node padding**: ensure `flowchart.padding` is at least `24` (CJK chars are ~50% wider than Latin)
   774→   774→2. **Text too long**: use `<br>` for manual line breaks, or shorten text
   775→   775→3. **Canvas too narrow**: use `width: fit-content` on `#diagram` container (🚫 NEVER use `max-width` — Mermaid SVG width is unpredictable)
   776→   776→4. **Node spacing too small**: increase `nodeSpacing` and `rankSpacing` (recommended 60+)
   777→   777→5. **When using classDef**: ensure `font-size` isn't too large, 12-14px is ideal
   778→   778→
   779→   779→**Correct approach for long-text nodes**:
   780→   780→```mermaid
   781→   781→flowchart LR
   782→   782→    A["这是一段比较长的<br>需要换行的文字"]
   783→   783→    B["用引号包裹节点文字<br>可以使用 HTML 标签"]
   784→   784→```
   785→   785→
   786→   786→**Key configuration**:
   787→   787→```javascript
   788→   788→mermaid.initialize({
   789→   789→  flowchart: {
   790→   790→    padding: 32,
   791→   791→    nodeSpacing: 80,
   792→   792→    rankSpacing: 80,
   793→   793→    htmlLabels: true,
   794→   794→    wrappingWidth: 160,
   795→   795→  }
   796→   796→});
   797→   797→```
