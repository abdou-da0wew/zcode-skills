    21→    21→### 1. Paper Search
    22→    22→
    23→    23→- **URL**: `GET /api/paper/search`
    24→    24→- **Price**: Free
    25→    25→- **Description**: Search by paper title; returns low-cost screening fields such as paper ID, title, DOI, venue, first author, citation bucket, and year.
    26→    26→
    27→    27→**Request Parameters:**
    28→    28→
    29→    29→| Parameter | Type | Required | Description |
    30→    30→|--------|------|------|------|
    31→    31→| page | number | Yes | Page number (current online definition says it starts at 1) |
    32→    32→| size | number | No | Items per page, maximum 20 |
    33→    33→| title | string | Yes | Paper title |
    34→    34→
    35→    35→**Response Fields:**
    36→    36→
    37→    37→| Field | Description |
    38→    38→|--------|------|
    39→    39→| id | Paper ID |
    40→    40→| title | Paper title |
    41→    41→| title_zh | Paper title (Chinese) |
    42→    42→| doi | DOI |
    43→    43→| first_author | First author |
    44→    44→| n_citation_bucket | Citation bucket: `0`, `1-10`, `11-50`, `51-200`, `200-1000`, `1000-5000`, `5000+` |
    45→    45→| venue_name | Venue title |
    46→    46→| year | Publication year |
    47→    47→| total | Total count |
    48→    48→
    49→    49→**curl Example:**
    50→    50→```bash
    51→    51→curl -X GET \
    52→    52→  'https://publicapi.chatglm.cn/chatglm_public/skill/aminer/api/paper/search?page=1&size=10&title=Looking+at+CTR+Prediction+Again%3A+Is+Attention+All+You+Need' \

    99→    99→### 3. Paper QA Search
   100→   100→
   101→   101→- **URL**: `POST /api/paper/qa/search`
   102→   102→- **Price**: ¥0.05/call
   103→   103→- **Description**: AI-powered intelligent Q&A search; supports natural language queries and structured keyword search.
   104→   104→
   105→   105→**Request Parameters:**
   106→   106→
   107→   107→| Parameter | Type | Required | Description |
   108→   108→|--------|------|------|------|
   109→   109→| use_topic | boolean | Yes | When `true`, searches with topic fields and/or keywords extracted from `query`; when `false`, only `title`/`doi` are read and `query` is ignored. Set `true` for any `query` or topic search. |
   110→   110→| topic_high | string | No | Valid when use_topic=true; keywords that must match (AND logic). Nested array format: `[["termA","termB"],["termC"]]` — outer AND, inner OR. |
   111→   111→| topic_middle | string | No | Strongly boosted terms; same format as topic_high. |
   112→   112→| topic_low | string | No | Weakly boosted terms; same format as topic_high. |
   113→   113→| title | []string | No | Title query; the only text field read when use_topic=false. |
   114→   114→| doi | string | No | Exact DOI query. |
   115→   115→| year | []number | No | Year filter array. |
   116→   116→| sci_flag | boolean | No | Return SCI papers only. |
   117→   117→| n_citation_flag | boolean | No | Boost papers with high citation counts. |
   118→   118→| size | number | No | Maximum number of results to return. |
   119→   119→| offset | number | No | Offset. |
   120→   120→| force_citation_sort | boolean | No | Sort entirely by citation count. |
   121→   121→| force_year_sort | boolean | No | Sort entirely by year. |
   122→   122→| author_terms | []string | No | Author name query; OR relationship within array; include multiple variants. |
   123→   123→| org_terms | []string | No | Institution name query; OR relationship within array. |
   124→   124→| author_id | []string | No | Author entity ID filter; accepts single ID or ID list. OR relationship with author_terms when both are provided. |
   125→   125→| org_id | []string | No | Institution entity ID filter; accepts single ID or ID list. OR relationship with org_terms when both are provided. |
   126→   126→| venue_ids | []string | No | Conference/journal ID list filter. |
   127→   127→| query | string | No | Raw natural language question (slower); system auto-extracts keywords. Takes precedence over topic_high when both are provided. Only effective with use_topic=true; with `false` it is silently ignored and the call returns 403 "no data". |
   128→   128→
   129→   129→**Response Fields:**
   130→   130→
   131→   131→| Field | Description |
   132→   132→|--------|------|
   133→   133→| data | Paper ID list |
   134→   134→| id | Paper ID |
   135→   135→| title | Paper title |
   136→   136→| title_zh | Title (Chinese) |
   137→   137→| doi | DOI |
   138→   138→| Total / total | Total count |
   139→   139→
   140→   140→**curl Example (natural language Q&A):**
   141→   141→```bash
   142→   142→curl -X POST \
   143→   143→  'https://publicapi.chatglm.cn/chatglm_public/skill/aminer/api/paper/qa/search' \
   144→   144→  -H 'Content-Type: application/json;charset=utf-8' \
   145→   145→  -H 'Authorization: ${AMINER_API_KEY}' \
   146→   146→  -H 'X-Platform: openclaw' \
   147→   147→  -d '{"use_topic": true, "query": "deep learning protein structure prediction", "size": 10, "sci_flag": true}'
   148→   148→```
   149→   149→
   150→   150→**curl Example (structured keywords):**
   151→   151→```bash
   152→   152→curl -X POST \
   153→   153→  'https://publicapi.chatglm.cn/chatglm_public/skill/aminer/api/paper/qa/search' \
   154→   154→  -H 'Content-Type: application/json;charset=utf-8' \
   155→   155→  -H 'Authorization: ${AMINER_API_KEY}' \
   156→   156→  -H 'X-Platform: openclaw' \
   157→   157→  -d '{
   158→   158→    "use_topic": true,
   159→   159→    "topic_high": "[[\\"transformer\\",\\"self-attention\\"],[\\"protein folding\\"]]",
   160→   160→    "topic_middle": "[[\"AlphaFold\"]]",
   161→   161→    "sci_flag": true,
   162→   162→    "force_citation_sort": true,
   163→   163→    "size": 10
   164→   164→  }'
   165→   165→```
   166→   166→
   167→   167→> **Prefer Paper QA Search Pro; use this legacy endpoint sparingly.**  
   168→   168→> Default almost all paper Q&A / topic / filter searches to **Paper QA Search Pro**. Keep this legacy API **only** for `topic_high/topic_middle/topic_low` structured OR/AND mode that Pro does not support. Do not start with this endpoint by default.

   172→   172→### 3b. Paper QA Search Pro
   173→   173→
   174→   174→> **Preferred default** for paper Q&A / topic / multi-filter search. Prefer this over legacy Paper QA Search whenever possible.
   175→   175→
   176→   176→- **URL**: `POST /api/v3/paper/qa/searchPro`
   177→   177→- **Price**: ¥0.70/call
   178→   178→- **Description**: Upgraded paper Q&A search. Supports natural-language understanding (`query_type=auto`), author/org/venue/year/citation filters, boolean terms, and cursor pagination. Default page size is fixed at **10** (not client-configurable on the open platform). Card response returns compact fields only.
   179→   179→
   180→   180→**Request Parameters:**
   181→   181→
   182→   182→| Parameter | Type | Required | Description |
   183→   183→|--------|------|------|------|
   184→   184→| query | string | No | Search text, max 500. Required when `query_type` is not `auto`. |
   185→   185→| query_type | string | No | `auto` / `topic` / `keywords` / `title` / `identifier`. Default `auto`. |
   186→   186→| cursor | string | No | Pagination cursor (16–256 chars). On next page, request body may contain **only** `cursor`. |
   187→   187→| authors | []string | No | Author names; OR within list; max 100 |
   188→   188→| author_ids | []string | No | Author IDs; OR with `authors` |
   189→   189→| organizations | []string | No | Organization names; OR within list |
   190→   190→| organization_ids | []string | No | Organization IDs; OR with `organizations` |
   191→   191→| venues | []string | No | Venue names, e.g. `["NeurIPS"]` |
   192→   192→| venue_ids | []string | No | Venue IDs; OR with `venues` |
   193→   193→| year_values | []number | No | Exact years; mutually exclusive with `year_from`/`year_to` |
   194→   194→| year_from | number | No | Start year (inclusive) |
   195→   195→| year_to | number | No | End year (inclusive); must be ≥ `year_from` |
   196→   196→| languages | []string | No | Hard language filter, e.g. `["en","zh"]` |
   197→   197→| language_preference | string | No | Soft preference boost: `zh` / `en` |
   198→   198→| has_chinese_title | boolean | No | Require / forbid Chinese title |
   199→   199→| has_abstract | boolean | No | Require / forbid abstract |
   200→   200→| min_citations | number | No | Minimum citation count (inclusive) |
   201→   201→| max_citations | number | No | Maximum citation count (inclusive) |
   202→   202→| all_terms | []string | No | All terms must match; max 20 |
   203→   203→| any_terms | []string | No | At least one term must match |
   204→   204→| exclude_terms | []string | No | Exclude if any term matches |
   205→   205→| search_in | string | No | Scope for all/any/exclude only: `all` / `title` / `title_keywords` / `abstract` |
   206→   206→| paper_ids | []string | No | Restrict to paper IDs |
   207→   207→| exclude_paper_ids | []string | No | Exclude paper IDs |
   208→   208→| dois | []string | No | DOI filter |
   209→   209→| sort | string | No | `relevance` / `balanced` / `recent` / `citation` |
   210→   210→
   211→   211→**Response Fields (open-platform envelope):**
   212→   212→
   213→   213→| Field | Description |
   214→   214→|--------|------|
   215→   215→| success | Whether the call succeeded |
   216→   216→| code | HTTP-style status: 200/400/410/500/502/503/504 |
   217→   217→| message / msg | Status text; success often `"success"` or empty |
   218→   218→| data | Business payload; usually `null` on failure |
   219→   219→| data.items | Paper list (card view, compact fields only) |
   220→   220→| data.items[].paper_id | Paper ID |
   221→   221→| data.items[].title | Title (English/original) |
   222→   222→| data.items[].title_zh | Title (Chinese) |
   223→   223→| data.items[].authors[].name | Author English name |
   224→   224→| data.items[].authors[].name_zh | Author Chinese name |
   225→   225→| data.items[].year | Publication year (may be omitted) |
   226→   226→| data.total.value | Hit count estimate |
   227→   227→| data.total.relation | `eq` / `gte` / `unknown` |
   228→   228→| data.next_cursor | Next-page cursor; null/omitted when no more pages |
   229→   229→| data.warnings | Business warnings (`code` / `message`) |
   230→   230→
   231→   231→**Notes:**
   232→   232→- Page size is fixed at 10; do **not** send `size` / `view` / `facets` / internal debug flags.
   233→   233→- Pagination: first page → read `next_cursor` → next page body is `{"cursor":"..."}` only.
   234→   234→- Always append paper URL: `https://www.aminer.cn/pub/{paper_id}`.
   235→   235→
   236→   236→**curl Example:**
   237→   237→```bash
   238→   238→curl -X POST \
   239→   239→  'https://publicapi.chatglm.cn/chatglm_public/skill/aminer/api/v3/paper/qa/searchPro' \
   240→   240→  -H 'Content-Type: application/json;charset=utf-8' \
   241→   241→  -H 'Authorization: ${AMINER_API_KEY}' \
   242→   242→  -H 'X-Platform: openclaw' \
   243→   243→  -d '{
   244→   244→    "query": "大模型比较新的高引论文",
   245→   245→    "query_type": "auto",
   246→   246→    "sort": "balanced",
   247→   247→    "year_from": 2024,
   248→   248→    "min_citations": 30
   249→   249→  }'
   250→   250→```
   251→   251→
   252→   252→**curl Example (next page):**
   253→   253→```bash
   254→   254→curl -X POST \
   255→   255→  'https://publicapi.chatglm.cn/chatglm_public/skill/aminer/api/v3/paper/qa/searchPro' \
   256→   256→  -H 'Content-Type: application/json;charset=utf-8' \
   257→   257→  -H 'Authorization: ${AMINER_API_KEY}' \
   258→   258→  -H 'X-Platform: openclaw' \
   259→   259→  -d '{"cursor":"<NEXT_CURSOR_FROM_PREVIOUS_RESPONSE>"}'
   260→   260→```

   264→   264→### 4. Paper Info
   265→   265→
   266→   266→- **URL**: `POST /api/paper/info`
   267→   267→- **Price**: Free
   268→   268→- **Description**: Batch-retrieve lightweight paper cards by paper ID, including abstract slice, year, venue ID, author list, and author count.
   269→   269→
   270→   270→> **Mandatory Parameter Constraints (High Priority)**
   271→   271→> 1. `paper_info` only supports the batch parameter `ids` (array); it does not support a single `paper_id`.
   272→   272→> 2. `paper_detail` only supports the single-paper parameter `id` (string); in the client `raw` function wrapper, the corresponding parameter name is `paper_id`.
   273→   273→> 3. Never pass `ids` to `paper_detail`; doing so will trigger a parameter error (e.g., `unexpected keyword argument 'ids'`).
   274→   274→> 4. If many results are matched and the user has not specified a count, default to querying only the top 10 details to avoid unnecessary costs.
   275→   275→
   276→   276→**Request Parameters:**
   277→   277→
   278→   278→| Parameter | Type | Required | Description |
   279→   279→|--------|------|------|------|
   280→   280→| ids | []string | Yes | Paper ID array, maximum 100 |
   281→   281→
   282→   282→**Response Fields:**
   283→   283→
   284→   284→| Field | Description |
   285→   285→|--------|------|
   286→   286→| id | Paper ID |
   287→   287→| title | Paper title |
   288→   288→| abstract_slice | Partial abstract |
   289→   289→| authors | Author list (includes `name` / `name_zh`) |
   290→   290→| author_count | Total author count |
   291→   291→| issue | Volume number |
   292→   292→| raw | Journal name |
   293→   293→| venue | Journal info object |
   294→   294→| venue_id | Venue ID |
   295→   295→| year | Publication year |
   296→   296→
   297→   297→**curl Example:**
   298→   298→```bash
   299→   299→curl -X POST \
   300→   300→  'https://publicapi.chatglm.cn/chatglm_public/skill/aminer/api/paper/info' \
   301→   301→  -H 'Content-Type: application/json;charset=utf-8' \
   302→   302→  -H 'Authorization: ${AMINER_API_KEY}' \
   303→   303→  -H 'X-Platform: openclaw' \
   304→   304→  -d '{"ids": ["53e9ab9bb7602d97023e53b2", "53e9a98eb7602d9703e42e5a"]}'
   305→   305→```
   306→   306→
   307→   307→**Usage Note:**
   308→   308→
   309→   309→`paper_info` is a batch endpoint. Always pass `ids` as an array, even when querying only one paper.

  1150→  1150→
  1151→  1151→| Code | Meaning | Recommended Action |
  1152→  1152→|------|---------|-------------------|
  1153→  1153→| 401 | Token invalid or expired | Re-generate token at [Console](https://open.aminer.cn/open/board?tab=control) |
  1154→  1154→| 403 | Insufficient balance or permission denied | Top up account or check token scope |
  1155→  1155→| 404 | Entity not found | Verify the ID is correct |
  1156→  1156→| 429 | Rate limit exceeded | Wait a few seconds and retry |
  1157→  1157→| 500 / 502 / 503 / 504 | Server error (transient) | Retry with exponential backoff (1s → 2s → 4s) |
  1158→  1158→
  1159→  1159→> For `4xx` errors (except 429), do not retry — fix the request parameters first.
