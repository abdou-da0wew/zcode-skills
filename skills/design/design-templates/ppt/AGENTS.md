# Deck Templates Agent Rules

This directory is slide-carrier only.

Read a deck template here only after the top-level `INDEX.md` carrier gate has confirmed the user wants PPT/deck output (slides, presentation, pitch deck, roadshow deck).

Do not enter this directory for topic keywords alone, including weekly report, report, course, financing, or launch.

Read the selected template `SKILL.md` first. Do not read `pattern.html` by default. Treat pattern files as layout references, not source code to copy.
