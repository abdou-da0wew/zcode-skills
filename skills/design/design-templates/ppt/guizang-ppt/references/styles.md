# Magazine Directions

5 **preset directions**, each bundling "which theme palette / which layouts / how many slides / how to write chrome copy" so you don't offer 5 unrelated options during the 6-question clarification.

> Inspiration: the "20 design philosophies × 5 streams" of [alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design) — compressed into 5 magazine-flavored directions, each mapped to one entry in `themes.md` plus certain combinations in `layouts.md`.

---

## When to use this document

At the start of SKILL.md `Step 1 · Requirement clarification`: **have the user pick one of these 5 directions first**, then ask about palette / duration / audience / outline. The flow:

```
1. User says "I want to build a talk deck"
2. You (the agent) present the 5 directions (copy the 1-line summaries below)
3. User picks one (or says "not sure, you recommend")
4. The chosen direction answers the "theme palette" and "slide count" questions; ask the remaining 4
```

**Hard rule**: the direction must be one of the 5 below, no mixing. Mixing = the failure path validated by huashu-design (brand asset protocol v1). If the user dislikes all 5, gently steer them to the closest one, then allow slight tone customization in `chrome` / `kicker` — **never recolor**.

## 1. Monocle Editorial · international magazine style ✦ default recommendation

**Keywords**: restraint, intellectual, transnational, *taste*

| Recipe | Choice |
|---|---|
| Theme palette | 🖋 Ink Classic |
| Recommended slide count | 18–24 slides (60% non-hero / 40% hero) |
| Primary layouts | **1 cover / 2 chapter dividers / 4 text+image / 8 big quote / 10 image-text mix** |
| Chrome copy | `Vol.04 · Spring 2026` / `Act II · 12 / 24` / `lukew.com · 2026.04` |
| Kicker style | short English + middle dot: `THE TWIST` / `BUT` / `DEC.` |
| Foot copy | `Page 12 · A New Way to Work` |

**Good for**: commercial launches, industry briefings, product announcements, personal-brand recaps. **Pick this by default** — it rarely goes wrong.

**Counter-examples**: deep technical reports (density too low), ops reviews full of tables (no fitting layout).

**Visual anchors**: *Monocle* / *Apricot Magazine* / *A Book Apart* / *Apartamento*.

## 2. WIRED Tech · data + engineering

**Keywords**: hard data, pipelines, comparison, futuristic

| Recipe | Choice |
|---|---|
| Theme palette | 🌊 Indigo Porcelain |
| Recommended slide count | 14–18 slides (light, data-dense) |
| Primary layouts | **1 cover / 3 big-number stat / 6 pipeline / 7 question page / 9 before-after** |
| Chrome copy | `Q2 / 2026 · Field Report` / `Data · 03` / `Eng Notes` |
| Kicker style | all caps + numbers: `38× FASTER` / `RUNTIME 04` / `CASE 02` |
| Foot copy | `Page 03 · benchmark` / `methodology footnote` |

**Good for**: technical launches, research sharing, benchmark reports, engineering-team internal comms, AI product demo days.

**Counter-examples**: humanities quote-sharing (too cold), art brands (not warm enough).

**Visual anchors**: *WIRED* longform / *MIT Technology Review* / *The Pudding* / *Stripe Press*.

**Special advice**: each stat-card's `stat-label` uses monospace English (core of the WIRED look); skip thousands separators on numbers (not engineering enough) — use `K` / `M` / `×` shorthand instead.

---

## 3. Kinfolk Slow · slow living / humanities

**Keywords**: whitespace, serif, warmth, private salons

| Recipe | Choice |
|---|---|
| Theme palette | 🍂 Kraft Paper |
| Recommended slide count | 9–12 slides (slow, airy, low density) |
| Primary layouts | **1 cover / 4 text+image / 8 big quote / 10 image-text mix / 2 chapter dividers** |
| Chrome copy | `Vol.07 · Autumn` / `Letter · 03` / `Notes from Kyoto` |
| Kicker style | short phrases with a period: "For a friend." / "Late autumn." / "Letter Three" |
| Foot copy | `Page 03 · Letter Three` / `2026 · Spring Issue` |

**Good for**: private salons, book clubs, interview recaps, lifestyle brands, personal essays.

**Counter-examples**: product launches (too slow), technical talks (too soft), serious data (density too low).

**Visual anchors**: *Kinfolk* / *The Gentlewoman* / *Cereal* / *Drift Magazine*.

**Special advice**:
- **Deliberately keep the slide count under 10** — Kinfolk's core is "less is more", don't stuff it
- Lean on Layout 8 (big quote) and Layout 10 (image-text mix)
- Avoid Layout 3 (big-number stat) — clashes with the temperament
- `<title>` text, chapter names, and kickers all use serif + short literary phrases

## 4. Domus Architectural · architecture / spatial

**Keywords**: scale, geometry, asymmetry, restrained showing-off

| Recipe | Choice |
|---|---|
| Theme palette | 🌙 Dune |
| Recommended slide count | 12–18 slides (medium density, strong visuals) |
| Primary layouts | **1 cover / 2 chapter dividers / 5 image grid / 9 before-after / 10 image-text mix** |
| Chrome copy | `Spazio 09 · Project File` / `Plan · 03` / `Fig.4` |
| Kicker style | number + category: `PROJECT 04` / `SECTION B` / `FIGURE 12` |
| Foot copy | `Page 09 · West Wing` / `1:200 scale` |

**Good for**: design / architecture case sharing, product design reviews, brand visual launches, gallery-style portfolio presentation.

**Counter-examples**: quote-sharing (too rigid), technical deep dives (weak at pipelines).

**Visual anchors**: *Domus* / *Apartamento* / *Mark Magazine* / *Pin-Up*.

**Special advice**:
- **Every hero page keeps 60% empty** — don't stuff it; the architectural feel comes from breathing room
- Use Layout 5 (image grid) a lot but with **only 4 large images**, never 6 small ones
- Keep `chrome` copy austere — English + numbers only

## 5. Lab / Reference · academic + craft manual

**Keywords**: restraint, figures and tables, reproducibility, engineer-friendly

| Recipe | Choice |
|---|---|
| Theme palette | 🌿 Forest Ink |
| Recommended slide count | 16–24 slides (dense, with figures) |
| Primary layouts | **1 cover / 2 chapter dividers / 3 big-number stat / 6 pipeline / 9 before-after** |
| Chrome copy | `Field Notes · Vol.II` / `Section 3.2 · Method` / `Reference 04` |
| Kicker style | numbered: `§ 3.2` / `Ref. 04` / `Method 01` |
| Foot copy | `Page 12 · 3.2 Calibration` / `appendix A` |

**Good for**: academic sharing, internal research recaps, sustainability / nature topics, long-cycle product retrospectives, method-driven craft talks (coffee / perfume / tea).

**Counter-examples**: commercial launches (too detached), marketing campaigns (not catchy enough).

**Visual anchors**: *National Geographic* (classic era) / *Hand-Eye Magazine* / *Nautilus* / *MIT Press* book layouts.

**Special advice**:
- Heavy use of `meta-row` for sources, methods, citations
- Use `<figcaption class="img-cap">` **more often than the other directions** — number every figure
- `kicker` uses § section numbers, not exclamations

## Decision record (mandatory before generating)

After picking a direction, **create or update `project-notes.md` in the project directory** (or `outline-v1.md`); the first line states:

```markdown
# [Talk Title] · Project Notes

- Direction: **Monocle Editorial** (from `references/styles.md`)
- Theme palette: 🖋 Ink Classic
- Audience: internal team (product + design)
- Duration: 25 min · about 18 slides
- Chrome style: Vol.04 / Act II / 12 of 18
- Kicker style: short English + middle dot
```

Update this section on every direction adjustment in later iterations. **Never switch direction midway** — the tonal differences between the 5 directions are bigger than they look; mixing tears the deck apart.

---

## ❌ Don'ts

- ❌ Mixing layout choices across directions (e.g. Monocle with multi-page Layout 6 pipelines plus Kinfolk-style chrome) — messy
- ❌ Inventing a 6th direction ("I want 'tech + literary' style") — gently steer to the closest one and note that mixes have a very high historical failure rate
- ❌ Switching direction midway, e.g. deciding at slide 8 that "Kinfolk would be better" — the first 7 slides are wasted; either restart everything or commit to the original direction
- ❌ Spending effort on layouts that don't belong to the direction (e.g. 4 pages of Layout 6 pipeline in Kinfolk) — a signal you picked the wrong direction

## ✅ Dos

- ✅ Choose only among the 5 directions; once chosen, let the direction answer the other 5 clarification questions
- ✅ State the direction on the first line of `project-notes.md` and keep it unchanged
- ✅ Let the chrome / kicker / foot text slots "speak for" the direction — they carry half its recognizability
- ✅ If unsure, **default to Monocle Editorial** — the lowest-failure-rate fallback of the 5
