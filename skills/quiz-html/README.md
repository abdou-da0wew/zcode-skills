# quiz-html · Web Quiz Page Builder

Turns a question array → a standalone HTML practice page.

## ✨ Feature Overview

- 📂 **Dual filtering**: category (subject / submodule) + study status (mastered / untried / mistakes)
- 🎯 **4 question types**: multiple choice / true-false / fill-in-the-blank / short answer
- 🤖 **Smart answering**: selecting ≠ submitting — change answers freely; one retry offered on a first wrong answer
- ⌨️ **Keyboard shortcuts**: A/B/C/D · Enter · ← → · Space
- 📝 **Mock exam mode**: pick question count + time limit + single submission + results page
- 🧠 **Memory tips**: questions with a `memory_tip` field are highlighted
- 🌓 **Theme toggle**: light / dark themes, remembered via localStorage
- 💾 **Progress persistence**: the browser remembers each question's state across sessions
- 📱 **Mobile friendly**: works on phones too

## 🚀 Quick Start

```bash
# 1. Prepare a question JSON file (array)
cat > /tmp/q.json << 'EOF'
[
  {"type":"single_choice","prompt":"1+1=?","options":["A. 1","B. 2","C. 3"],"answer":"B",
   "explanation":"Basic arithmetic","category":"Math / Addition & subtraction","level":1}
]
EOF

# 2. Build the HTML
python3 scripts/build_quiz_html.py /tmp/q.json --title "Math Practice" --open
```

## 🔗 Integration with quiz-mastery

This skill does not generate questions itself; it handles only the "questions → web page" step.
For generating / importing questions use `quiz-mastery`. Full pipeline:

```
quiz-mastery generates questions
       ↓
   questions JSON
       ↓
  ask the user: "Want this as a web page?"
       ↓ user says yes
   quiz-html  ← you are here
       ↓
  generate .html
       ↓
 open in browser → user starts practicing
```

## 📝 Question Fields

| Field | Required | Type | Description |
|---|---|---|---|
| `type` | ✅ | string | `single_choice` / `true_false` / `fill_blank` / `short_answer` |
| `prompt` | ✅ | string | Question text |
| `options` | choice questions | array | `["A. xxx", "B. yyy", ...]` |
| `answer` | ✅ | string | Correct answer |
| `explanation` | recommended | string | Explanation (supports `**bold**`, `*italic*`, `` `code` ``) |
| `knowledge_point` | recommended | string | Knowledge point (used for sidebar grouping) |
| `category` | recommended | string | Category path, suggested format `"Subject / Submodule"` |
| `level` | optional | int | Difficulty 1-3 |
| `memory_tip` | optional | string | Memory tip, highlighted in an orange card |

## ⌨️ Keyboard Shortcuts

| Key | Action |
|---|---|
| `A` `B` `C` `D` | Select an option |
| `T` `F` | True/false questions |
| `Enter` | Submit |
| `←` `→` | Previous / next question |
| `Space` | Show answer |
| `Ctrl/⌘+Enter` | Submit the whole mock exam |

## 🛠️ Command-Line Options

```
python3 build_quiz_html.py <questions.json> [options]

  --output, -o    Output HTML path (default: same directory as the questions file)
  --title         Page title
  --subtitle      Subtitle (auto-generated by default)
  --id            Question bank ID (used for localStorage isolation)
  --open          Open in the browser after generating
```
