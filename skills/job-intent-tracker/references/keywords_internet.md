# Internet Product / Operations / Project Management Keyword Library

Used for: judging fit, generating profiles, ATS keyword coverage checks.

## Product Manager (PM)

**Must-have signal words**
- Requirements docs (PRD), requirement reviews, product planning, product iterations
- User interviews, user personas, JTBD, Persona
- Data-driven, A/B testing, funnel analysis, retention, conversion rate
- Cross-department collaboration, driving delivery, project management
- 0-1, 1-N, growth, monetization

**Direction-specific keywords**
- Consumer (C-end): user growth, social virality, content ecosystem, UGC, recommendation-algorithm literacy
- Business (B-end) / SaaS: customer success, renewals, ARR, PLG, CRM
- Internationalization / going global: localization, compliance, multilingual, overseas payments
- AI products: LLM, prompt engineering, model evaluation, RAG, Agent
- Tooling: user experience, efficiency, workflow, productivity

**Nice-to-have**
- SQL, Python, Figma, prototyping tools
- Industry report output, PR experience, public speaking

## Operations

**Must-have**
- User ops, content ops, campaign ops, community ops
- Growth hacking, AARRR, private traffic, public traffic
- GMV, ROI, CAC, LTV, conversion funnel
- SOPs, process-ization, replicability

**Direction-specific**
- Content ops: topic selection, content matrix, KOLs, viral-hit methodology
- User ops: segmentation, lifecycle, push strategy, CRM
- Campaign ops: seasonal marketing, brand+performance combined, budget management
- Community ops: community tiering, KOCs, conversion paths
- Live-streaming / e-commerce ops: product selection, influencer partnerships, GMV, repeat purchase

## Project Manager (PMP / TPM)

**Must-have**
- Project scheduling, milestones, risk management, stakeholder management
- Agile / Scrum / Kanban, Sprint planning, retro
- Cross-team collaboration, cross-timezone, escalation

**Nice-to-have**
- PMP certificate, PRINCE2, CSM
- Tools: Jira, Confluence, Asana, Notion, Linear, Lark Projects (Feishu)

## Red Flags (if these appear, it's not a good PM / operations profile)
- Large blocks of "participated in ___" — no ownership
- No numbers / percentages / quantified results at all
- All soft-skill descriptions, no concrete actions
