# Tech / Engineering / Data Keyword Library

## Backend / Server-Side

**Must-have languages & frameworks**
- Mainstream languages: Java / Go / Python / C++ / Rust / Node.js
- Web frameworks: Spring Boot, Gin, FastAPI, Django, Express, NestJS
- Microservices: Spring Cloud, gRPC, Service Mesh, Istio
- Middleware: Kafka, RabbitMQ, Redis, ZooKeeper, Etcd

**System design signals**
- High concurrency, high availability, distributed systems, CAP, consistency, rate limiting, degradation, circuit breaking
- Storage: MySQL, PostgreSQL, MongoDB, ClickHouse, HBase, TiDB
- Caching strategy, read-write splitting, database sharding
- Containerization: Docker, Kubernetes, Helm
- Cloud: AWS / GCP / Alibaba Cloud / Tencent Cloud / Volcano Engine

**Level judgment**
- Junior (1-3 yrs): completes module development independently
- Mid-level (3-5 yrs): owns subsystem design, code review, mentors newcomers
- Senior (5-8 yrs): architecture design, cross-team collaboration, tech selection
- Staff / Principal (8+ yrs): business architecture, technology strategy, influence

## Frontend

**Must-have**
- HTML / CSS / JavaScript / TypeScript
- Frameworks: React, Vue, Angular, Svelte
- Build tooling: Webpack, Vite, Rollup, Turbopack
- State management: Redux, Zustand, Pinia, MobX
- Full-stack leaning: Next.js, Nuxt, Remix

**Nice-to-have**
- Cross-platform: React Native, Flutter, Electron, Tauri
- Performance: FCP / LCP / CLS, SSR, SSG, CDN
- Visualization: D3, ECharts, Three.js
- Micro-frontends: qiankun, single-spa, Module Federation

## Algorithms / Machine Learning

**Must-have**
- Math foundations: probability & statistics, linear algebra, optimization
- Classic ML: sklearn, XGBoost, LightGBM, feature engineering
- Deep learning: PyTorch, TensorFlow, JAX
- Training: distributed training, data parallelism, model parallelism, mixed precision
- Deployment: ONNX, TensorRT, TorchServe, Triton

**LLM / GenAI direction**
- Pretraining, SFT, RLHF, DPO, PPO
- RAG, vector retrieval, Embedding, Reranker
- Prompt engineering, Tool use, Agent, MCP
- Model evaluation: benchmarks, human evaluation, LLM-as-Judge
- Inference optimization: vLLM, quantization, KV cache, speculative decoding

**CV / NLP / RecSys sub-tracks**
- CV: detection, segmentation, OCR, video understanding, diffusion models
- NLP: classification, NER, QA, dialogue, information extraction
- RecSys: recall, coarse ranking, fine ranking, re-ranking, CTR / CVR, Cold Start

## Data / Data Warehouse

**Must-have**
- SQL (always tested; if shaky, instant pass)
- Warehouse modeling: dimensional modeling, star / snowflake, ODS/DWD/DWS/ADS
- Big data: Hive, Spark, Flink, Presto / Trino
- Scheduling: Airflow, DolphinScheduler
- BI: Tableau, PowerBI, Superset, Quick BI

## Data Analyst / Business Analytics

**Must-have**
- SQL (mid-level or above: window functions, CTEs, complex joins)
- Business understanding: can decompose a one-line stakeholder request into metrics + dimensions
- Experiment design: A/B tests, significance, sample size
- Tools: Python (pandas), R, advanced Excel, visualization tools

## DevOps / SRE

- CI/CD: Jenkins, GitLab CI, GitHub Actions, ArgoCD
- IaC: Terraform, Pulumi, Ansible, Chef
- Monitoring: Prometheus, Grafana, ELK, Datadog, SkyWalking
- Incident handling: on-call, SLO, SLA, error budgets, postmortems

## Red Flags
- Resume only says "familiar with / aware of / used" → weak
- Lists a pile of frameworks with no corresponding projects → fake
- No performance numbers / data scale at all → thin
